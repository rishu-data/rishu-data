# 💫 About Me:

👋 Hi, I'm Rishu Singh

Data Analyst | Business Intelligence | SQL | Power BI

I'm a B.Tech CSE (Data Science) student at Guru Gobind Singh Indraprastha University, passionate about using data to uncover insights, solve business problems, and support data-driven decision-making.

I work with SQL, Power BI, Excel, PostgreSQL, DAX, Python, and Tableau to transform raw data into meaningful business insights. My experience includes data cleaning, exploratory data analysis, data modeling, KPI development, dashboard design, reporting, and data storytelling.

I've built hands-on analytics projects across HR Analytics, Sales Analytics, Campus Recruitment, Mobile Sales, and Customer Analysis, focusing on translating business requirements into interactive dashboards and actionable insights.

- Write optimized SQL queries for data analysis

- Develop business-focused visualizations and reports
- Communicate insights through clear data storytelling

🚀 Currently Focusing On
